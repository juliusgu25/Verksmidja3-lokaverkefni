# Verksmidja3-lokaverkefni

## Uppsetning raspberry pi zero w2
Það reyndist dáldið þrjóskt að setja upp viðeigandi hugbúnað upp á tækið. https://github.com/respeaker/seeed-voicecard var einstaklega tregt þar það festist í lykkju um að vilja hörfa í ákveðna útgáfu. Hins vegar gátum við notað https://github.com/HinTak/seeed-voicecard sem var lagfærð útgáfa af búnaðinum og það tókst að setja hann upp klakklaust. Síðan fylgdum við https://wiki.seeedstudio.com/ReSpeaker_2_Mics_Pi_HAT_Raspberry/ frá A til Ö og lentum við ekki í neinum vandræðum með uppsetningu á honum. Hátalarinn reyndist einnig dáldið þrjóskur og þurfti að lóða hann mjög vel til þess að láta hann virka auk þess að lóða tengi sem lítið var til af.
